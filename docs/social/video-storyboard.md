# Presence 宣传短片分镜（Seedance 2.5 / 9:16）

目标：20–30 秒竖屏宣传片，讲清"agent 真的在那台机器上干活"。
核心叙事：**真实窗口里敲提示词 → 发送 → 镜头进入 agent → agent 用 Presence 像本地一样操作文件 → 远端机器执行 → 结果回到对话**。

## 一、生成策略（重要）

Seedance 这类图生视频 **写不好真实 UI 文字**（会变成乱码/变形）。所以采用混合：

| 镜头类型 | 做法 |
| --- | --- |
| DSH 窗口、文件树、终端、端口转发、聊天结果 | **实拍/录屏**（真实界面，可读） |
| 镜头推进、穿入屏幕、光效转场、GPU/机房氛围、抽象数据流 | **Seedance 生成**（不需要清晰文字） |
| 结尾 logo & 字幕 | 剪辑软件里做（矢量，清晰） |

生成参数建议：9:16、1080×1920、24fps、每段 5–8s、首帧用 `@图片1` 锁定；同一套 prompt 里保持"冷蓝科技感、体积光、浅景深、轻微手持晃动"风格词一致。

## 三、需要你提供的素材

1. **DSH 窗口录屏**（1080p 以上，60fps 最佳）：输入提示词、发送、agent 回复"搞定了"的完整一段（可加速/裁切）。
2. **文件树/编辑**录屏：展开远端目录、打开代码文件、保存。
3. **终端**录屏：执行 `nvidia-smi` 或训练启动命令，输出滚动 5s。
4. **确定性截图**：结果卡片、端口转发面板（用于实拍剪辑，不用 AI）。
5. 可选：真实 GPU 机器/机房的 5–10s 实拍或氛围视频（也可完全用 Seedance 生成）。

## 五、剪辑要点（剪映 / CapCut）

- **转场**：屏幕穿越用 "缩放+模糊" 手搓（不要用默认转场），配合 whoosh。
- **速度曲线**：#2 加速 200%，#9 回穿 300%，落点回正常速度。
- **叠加**：真实录屏上加一层 Seedance 生成的"数据流/光晕"素材，混合模式加色（Add/Screen），让实拍也有电影感。
- **音效**：键盘、发送、whoosh、终端键入、成功；低频垫底，节奏 90–110 BPM。
- **字幕**：只保留 3–4 句（#3/#5/#7/#11），其余靠画面；UI 里的文字不要再用字幕重复。
- **首帧**：封面就用视频 #1 的第一帧，和小红书首图同一套视觉。

## 六、和小红书图文的配合

- 图文 7 张：封面 / 工具 / 流程（可换成视频后改为一帧海报）/ 3 张真实截图 / 结尾。
- 视频作为"动态版"发第二条，或同篇附视频；视频前 3 秒必须是"敲提示词 + 发送"，这是钩子。
