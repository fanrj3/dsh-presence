# Presence 宣传短片分镜脚本（Seedance 2.5 · 竖屏 9:16）

> 用法：每个镜头是一段可直接喂给 Seedance 的连贯描述，`@图片N` 是参考图占位符——你按本文件最后的「参考图清单」把图配好，Seedance 里引用它们即可。
> **原则**：DSH 真实界面（窗口、对话、文件树、终端）一律用**真实录屏/截图**做底，Seedance 只负责"穿越屏幕、光效、氛围、转场"。AI 生成不了可读的 UI 文字，硬生成会糊。

建议成片 28–32 秒；竖屏 1080×1920，24fps；背景音乐 90–110 BPM，前 3 秒必须是「敲提示词 + 回车」。

---

## 镜头 1（0–4s）· 敲下那句提示词

真实桌面上开着 DSH，深色主题窗口占画面约三分之二，输入框光标缓慢闪烁。画面从窗口右侧轻轻推近到输入框，手指在键盘上敲下一行字：「把 server 上的训练跑起来，挂了就修」。键盘声由轻到清晰，环境声压低。镜头落定在输入框里那行字上，停半拍。

**参考**：`@图片1`（DSH 主窗口，首帧）· `@图片2`（输入框特写，含提示词）
**制作**：真实录屏（60fps 最佳）
**Seedance prompt**：
```
电影级科技宣传片，竖屏。@图片1 作为首帧：深色桌面上打开着的 DSH 应用窗口。
镜头从右侧极缓推近窗口输入框，浅景深，冷蓝色调，屏幕微光映在桌面，
细微手持晃动，真实质感，24fps。@图片2 作为输入框特写插入参考。
```
**声音**：机械键盘敲击、低频环境垫底。

## 镜头 2（4–5.5s）· 回车

指尖按下回车，输入框里的文字微微一亮，气泡从输入框弹出、向上飞出画面。镜头猛地跟随气泡向屏幕深处推进，画面边缘出现速度模糊。

**参考**：`@图片2`（输入框）
**制作**：真实录屏 + 剪辑速度曲线
**Seedance prompt**：
```
竖屏特写：@图片2 中的输入框被按下回车，文字亮起，发光气泡从输入框弹射而出，
镜头跟随气泡高速向屏幕深处推进，速度模糊，蓝色光轨，电影感，24fps。
```
**声音**：发送音效（whoosh）＋ 一下轻微的低频冲击。

## 镜头 3（5.5–9s）· 镜头穿过屏幕，进入 agent 的世界

镜头穿过屏幕表面，真实的界面像玻璃一样碎成发光线条：窗口边框、文件树、终端提示符化作悬浮的蓝色数据流。一个由光点组成的「agent」在中央亮起，提示词卡片悬浮在它面前被展开、逐条读完。光线从卡片流向 agent，像在"理解"。

**参考**：`@图片1`（穿越前的窗口）· `@图片9`（品牌光感/结尾视觉，做配色参考）
**制作**：Seedance 生成
**Seedance prompt**：
```
镜头穿过 @图片1 的屏幕表面，真实界面化为悬浮的蓝色发光线条与数据流，
中心亮起由光点组成的抽象 agent，提示词卡片在它面前展开、逐行点亮，
光线从卡片流向 agent，深色空间，体积光，浅景深，冷蓝色调，24fps，无文字。
```
**声音**：低频上升的 swell，电子滴答像心跳。

## 镜头 4（9–13s）· 它开始像本地一样操作

agent 的光点伸出"手"，场景切换到远端文件系统：目录节点像本地文件夹一样悬浮展开，代码文件被拉开、高亮、光标在代码里移动、修改一处、保存。画面保持"这就是一台电脑"的熟悉感，只是所有元素都带一层淡淡的蓝色光晕。紧接着切到终端：命令被敲下，输出快速滚动。

**参考**：`@图片4`（远程文件面板，文件树）· `@图片5`（代码预览/编辑界面）· `@图片6`（终端输出）
**制作**：真实录屏为主，叠 Seedance 生成的光效层（Add/Screen 混合）
**Seedance prompt**：
```
@图片4 与 @图片5 的界面在深色空间中悬浮展开：目录节点像本地文件夹一样依次打开，
代码文件被拉开、高亮、光标移动并修改，随后画面切到 @图片6 的终端，
命令敲下、输出快速滚动，界面边缘带蓝色辉光，浅景深，轻微推进，无文字，24fps。
```
**声音**：清脆的 UI 点击声、终端键入声、风扇底噪。

## 镜头 5（13–16s）· 指令真的跑在那台机器上

镜头从终端画面拉出，落进一间昏暗的机房：机柜上的 GPU 指示灯成排闪烁，散热风扇高速旋转，尘埃在冷蓝色体积光里缓慢漂浮。镜头贴着机柜横移，景深把远处的灯带化成光斑。

**参考**：`@图片8`（机房/GPU 氛围素材，可选；没有就用 Seedance 生成）
**制作**：Seedance 生成（或真实机房实拍）
**Seedance prompt**：
```
电影级微距：昏暗机房，机柜上成排 GPU 指示灯闪烁，散热风扇高速旋转，
冷蓝色体积光中尘埃缓慢漂浮，镜头贴着机柜缓慢横移，浅景深，光斑虚化，
真实质感，24fps，无文字。
```
**声音**：机房低频轰鸣、风扇声，节奏鼓点渐强。

## 镜头 6（16–19s）· 训练在跑

特写：GPU 利用率曲线和进度条在暗色屏幕上推进，数据粒子沿着线条流动，画面有轻微的呼吸感。光线从屏幕溢出，照亮周围的空气。

**参考**：`@图片6`（真实训练/GPU 输出截图，作为画面参考）
**制作**：Seedance 生成 + 真实截图叠化
**Seedance prompt**：
```
暗色屏幕上，GPU 利用率曲线与训练进度条快速推进，发光的蓝色数据粒子沿曲线流动，
光线溢出屏幕照亮空气，浅景深，微距，冷蓝色调，轻微的镜头呼吸，24fps，无文字。
```
**声音**：持续的电子脉冲，鼓点继续推进。

## 镜头 7（19–23s）· 镜头掉头，穿过屏幕回到对话

镜头猛然后拉，从机房画面加速回穿屏幕，穿过发光的数据流，速度先快后慢，最后稳稳落在 DSH 的对话窗口上——屏幕上，agent 的回复正在逐字出现：「搞定了！结果如下：…」，下面是一张结果卡片。

**参考**：`@图片7`（结果卡片 / agent 回复截图）· `@图片1`（对话窗口）
**制作**：Seedance 转场 → 真实录屏结果页
**Seedance prompt**：
```
镜头从机房高速后拉，穿过发光的屏幕表面与蓝色数据流，速度先快后慢，
最后落在 @图片1 的深色对话窗口上，画面稳定，浅景深，光效拖尾，电影感，无文字。
```
**声音**：回拉 whoosh，落点一声轻"叮"。

## 镜头 8（23–26s）· 结果自己回来了

真实的 DSH 对话窗口占据画面，agent 的回复「搞定了！结果如下：…」逐字打完，结果卡片轻轻弹出。镜头缓慢推近结果卡片，卡片上的数字、图表、日志行依次亮起。此时画面右侧浮出一行小字：**「结果直接回到对话」**。

**参考**：`@图片7`（结果卡片截图，逐字稿）
**制作**：真实录屏 + 打字动效 + 字幕
**声音**：成功音效、轻微 UI 提示音。

## 镜头 9（26–30s）· 收尾

画面淡出到深色，中心浮出 Presence 的图标与一行 slogan：「把远程机器，变成本地工作区」。图标边缘扫过一道光，最后画面定住 1 秒。

**参考**：`@图片9`（品牌视觉/图标）
**制作**：剪辑合成（矢量，保证清晰）
**声音**：收尾重音，余音渐弱。

**拍摄建议**
- 所有真实界面统一深色主题、2x 缩放截取/录制，文字才够清晰；
- 录屏时关掉通知、隐藏真实主机名/IP（或最后打码）；
- Seedance 每段先生成 5–8 秒，挑最稳的一条，再用剪辑软件拼接；
- 全片只用「真实界面 + 光效」两种语言，不要在同一镜头里混用 AI 生成的 UI。

# 剪辑要点

- **转场**：#2→#3、#6→#7 用「缩放 + 方向模糊 + whoosh」手搓，别用默认转场。
- **速度**：#2 加速 200%，#7 回拉 300%，落点恢复正常。
- **叠加**：真实录屏上叠一层 Seedance 生成的"数据流/光晕"，混合模式 Add 或 Screen，实拍立刻有电影感。
- **字幕**：只保留 3 句关键文案（#3「它开始干活了」、#5「指令真的跑在那台机器上」、#9 slogan），其余靠画面。
- **封面**：用镜头 1 的第一帧，和小红书首图同一套视觉（浅色版或深色版保持一致）。
