# 小红书图文：Presence 发布视觉方案

这份文档回答两件事：**图该怎么设计**（尺寸、风格、分镜），以及**用什么软件做**（Windows 可用）。
文末附两版可直接改字的封面模板（`cover-light.png` / `cover-dark.png`，1080×1440）和重新生成脚本。

## 1. 平台规格（先记住这几个数）

| 项 | 规范 | 说明 |
| --- | --- | --- |
| 首图比例 | **3:4**，1080×1440 px | 发现页双列信息流里 3:4 占满卡片，点击面积最大；横图会被裁 |
| 主页九宫格 | 1:1 居中裁切 | 核心文字必须落在画面**正中央的 1:1 区域**，否则主页预览会丢字 |
| 底部安全区 | 约 200px | 笔记标题/作者信息会盖住底部，关键信息不要放最下面 |
| 右侧安全区 | 约 120px | 点赞/收藏按钮所在列 |
| 安全边距 | 四周 ≥ 120px | 干货/知识类图文尤其要留白 |
| 色彩 | sRGB | 用 Adobe RGB/P3 导出会发灰；导出前转 sRGB |
| 体积 | 1–3 MB | 太大被二次压缩；PNG 或高质量 JPG 均可 |
| 内页 | 同 1080×1440 | 一套图统一比例，视觉最整齐 |

> 参考：图叮 AI 的[封面尺寸与裁剪指南](https://tudingai.cn/blog/202606/cover-ai-bl-92179f/)，以及[免费封面制作工具说明](https://tudingai.cn/blog/202606/cover-free-tool-bl-0cffeb/)。平台规则会调整，发布前以小红书实际上传预览为准。

## 2. 科技产品图为什么"看起来高级"

爆款科技向图文基本是这四层叠加，不是裸截屏：

1. **统一底板**：渐变/纯色 + 细网格 + 柔和光晕（不要脏渐变、不要多色乱撞）。
2. **截屏装进"卡片/设备框"**：圆角 24–32px、轻微阴影、深色终端卡片配浅色底；不要直接贴原始截屏。
3. **排版层**：一张图只说一件事——大标题（80–110px 粗体）+ 一句副标题 + 一个截图主体 + 1–3 个标注/箭头。
4. **信息密度控制**：首图钩子，内页一页一个功能；数字、对比、前后差异最抓人。

Presence 建议视觉系统（模板里已经用上）：

| Token | 值 |
| --- | --- |
| 主色 | `#2F6BFF`（渐变到 `#5B9BFF`） |
| 辅助色 | `#7C3AED`（少量光晕） |
| 深色底 | `#0F172A → #111A33` |
| 浅色底 | `#F8FAFC → EAF2FF` |
| 正文/次要文字 | `#0F172A` / `#475569` / `#94A3B8` |
| 字体 | 中文：微软雅黑/思源黑体/苹方；英文数字：Cascadia Code 或 Consolas（等宽部分） |
| 圆角 | 卡片 28–32，chip 999 |
| 阴影 | `0 24px 60px rgba(15,23,42,.18)` 一类柔投影，别用硬黑投影 |

### 4.1 排版/合成（核心）

| 工具 | 适合 | 成本 | 备注 |
| --- | --- | --- | --- |
| **Figma** | 做一套可复用模板、多张图统一风格 | 免费版够用 | 推荐：组件化、导出 1080×1440、支持中文 |

| **稿定设计** | 电商/产品类模板多，改字即用 | 部分付费 | 适合快速出 2–3 版 |
| Photoshop | 精细修图/合成 | 付费 | 非必需 |

### 4.2 截屏美化（把裸截屏变成"产品图"）

| 工具 | 平台 | 说明 |
| --- | --- | --- |
| **Shots.so** | 浏览器（在线） | 渐变/网格背景 + 设备框 + 圆角阴影，免费档足够；注意截图会上传到它的服务器 |
| Screenify Studio | 桌面/在线 | 有免费档，支持设备框；本地处理 |
| Rotato / Angle | macOS 为主 | 3D 设备框更"苹果发布会"感，Windows 不适用 |
| **Snipaste / ShareX / Flameshot** | Windows | 截屏 + 标注（箭头/框/马赛克），ShareX 还能自动上传 |
| CleanShot X / Shottr / Xnapper | macOS | 截屏 + 自动美化背景，苹果生态首选 |

### 4.3 动图/短视频（可选，做第二条笔记）

- **ScreenToGif**（Windows，免费）：录屏→GIF/MP4，加键盘提示。
- **Screen Studio**（macOS）：自动缩放跟随鼠标，成片很"产品片"。
- OBS + 剪映：想要口播/长视频时用。

### 4.4 压缩与色彩

- 导出：PNG（文字锐利）或 JPG 质量 85–90，**sRGB**。
- 压到 1–3MB：[Squoosh](https://squoosh.app/)（在线）、ImageOptim（Mac）、`pngquant`/`oxipng`（命令行）。
- 记得清 EXIF（体积+隐私）。

## 5. 推荐工作流（一个人 1–2 小时出 7 张）

1. **准备素材**：按分镜逐个操作 DSH 截图（Win+Shift+S 或 Snipaste），每张截 2x 像素。
2. **美化截图**：Shots.so 选渐变底 + 圆角卡片（统一同一套背景），导出 PNG；或直接在 Figma 里画圆角矩形 + 阴影 + 放截图。
3. **排版**：Figma/即时设计建一个 1080×1440 画板，放标题/副标题/截图/标注；复制画板改内容，7 张保持同一栅格。
4. **导出**：sRGB、1080×1440、PNG。
5. **压缩**：Squoosh 压到 1–3MB。
6. **发布**：首图用模板（本目录两版可选），正文用"痛点 → 3 个功能点 → 怎么装 → 结尾提问"的结构。

## 6. 文案结构（科技向在小红书）

- **标题公式**：`身份/场景 + 反差 + 结果`，例如「让 AI 直接住进服务器｜SSH 零安装」「程序员效率：远程机器像本地一样用」。
- **正文**：开头 2 行说痛点（每次 ssh 都重新连接、远端装环境麻烦）→ 3 条功能（零安装/持久连接/端口转发）→ 怎么用（DSH 插件搜 Presence）→ 结尾提问引导评论。
- **标签**：#AI编程 #程序员 #效率工具 #SSH #远程开发 #MCP #开源 等 5–8 个，别堆 20 个。
- **不要**：夸大"替代所有工具"、把未实现能力写成已实现；技术受众对夸大很敏感。

### 高级光晕怎么做（研究结论）

主流做法就四层，Figma/PS 都能复现：

1. **底色**：深色竖向渐变 + 96px 技术网格（低透明度），避免纯黑死板。
2. **环境光晕（ambient glow）**：在卡片**后面**放 2–4 个巨大圆形渐变，透明度 20–40%，加 **Layer Blur 60–120**；Figma 里就是 `Effect → Layer blur`。参考 [Figma ambient glowing rings 教程](https://designerviet.com/threads/huong-dan-tao-hieu-ung-ambient-glowing-rings-trong-figma.21169/)。
3. **局部光斑（spotlight）**：径向渐变单独一层，混合模式 **Screen / Soft Light**，再复制一层"轻微模糊 + 降低不透明度"制造多层光深。参考 [PS 径向渐变 Screen 做法](https://phlearn.com/tutorial/add-gradient-in-photoshop/)、[Screen + 复制模糊的讨论](https://answers.fiverr.com/qa/10_graphics-design/119_image-editing/can-you-share-an-example-of-how-you-effectively-used-blending-modes-to-achieve-a-creative-effect-in-your-image-edits-r4063/?tab=comments#comment-20514)。
4. **质感**：叠 3–6% 噪点（grain）防渐变断层；卡片描边用 `rgba(255,255,255,.1)` 而不是纯白；文字加极轻白色 glow 提升可读性（背景复杂时）。参考 [uBlur 的 glow/shadow 教程](https://ublur.app/articles/how-to-add-drop-shadows-glow)。

在 Figma 里的 5 分钟配方：
1. 1080×1440 画板，深色渐变底（#090D1C → #101A36）。
2. 画 2 个 500px 圆，填蓝/紫，`Layer blur 80`，透明度 30%。
3. 放截图卡片（圆角 24、1px 白描边 8%），复制一层放后面，`blur 40`、透明度 25% 当投影光。
4. 叠一张噪点图，透明度 3–5%，混合模式 Overlay（或 Soft light）。
5. 导出 PNG，sRGB，1–3 MB（Squoosh 压缩）。

## 10. 高级质感的配方（你发的那张图拆解）

那张参考图的高级感不是"拍"出来的，是**六层叠出来的**（Figma/PS 都能做）：

1. **壁纸层**：深蓝 → 青 → 橙的极光渐变，加很大的高斯模糊（40–80px），再压暗四周做 **vignette**；关键是颜色要"脏"一点，不要纯色饱和。
2. **环境光**：在卡片后面放 2–3 个大圆径向渐变（蓝/青/橙），Layer Blur 80–120，透明度 20–35%。
3. **毛玻璃面板**：深色半透明 `rgba(10,15,30,.72)`，圆角 40，**1px 内高光**（顶部白 15–20%，底部 5%），外描边白 12–16%。Figma 里用 Background blur + 内阴影（白色、Y=1、Blur=0）。
4. **投影**：一个大而软（`0 40px 80px rgba(0,0,0,.45)`）+ 一个小而紧（`0 2px 6px rgba(0,0,0,.3)`）；投影颜色带一点壁纸的色相会更真实。
5. **内容**：截图本身圆角 32、内缩 16px、外描边白 8%，避免截图"贴死"在面板上。
6. **质感**：全局 3–5% 噪点（叠加模式 Overlay/Soft light）+ 轻微暗角；参考图右边还有一圈弧形屏幕边缘（用大圆角遮罩 + 外阴影模拟），以及悬浮在面板上的小组件（圆环进度、标签）。

对应到本目录：`shot-frame.png` 就是这个配方的 1080×1440 模板（壁纸 + 柔投影 + 毛玻璃 + 内高光 + 悬浮组件），把截图放进虚框即可；我把你给的 PNG 合进去后，会按这个叠层顺序出一版 1080×1440 和一张 1:1 备用。

> 参考来源：Figma 环境光做法（Layer blur 60+）、PS 径向渐变 + Screen 混合、多层复制模糊、噪点叠加。
